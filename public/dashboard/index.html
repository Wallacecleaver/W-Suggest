⚙️ Documentation & Variables d'Environnement

Le tableau de bord est protégé par le mot de passe défini dans votre fichier .env. Vous pouvez personnaliser les variables suivantes :

Variable Description Valeur par défaut
DASHBOARD_PASSWORD Mot de passe protégeant l'accès au tableau de bord Obligatoire pour accéder au dashboard
PORT Port d'écoute du serveur HTTP Express 8080
ENABLE_LOGGING Active l'enregistrement des journaux dans logs/ false
ENCRYPTION_KEY Clé secrète pour chiffrer les clés API des utilisateurs dans les URLs Stremio Optionnel
CACHE_TTL Durée de vie du cache en secondes 259200 (3 jours)
CACHE_MAX_SIZE Nombre maximum d'éléments dans le cache local 3000
REDIS_URL URL de connexion Redis si vous utilisez un cache externe Désactivé (mémoire locale)
